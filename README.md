# AI in Financial Policy — Demo

Static demo page presenting policy-attention analysis on AI in banking regulation and supervision.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Project layout

```
index.html          entry
styles/             tokens, base, layout, components
scripts/            small vanilla JS (scroll reveal)
assets/             figures, fonts, icons
notes/              internal design rules and structure
tools/              python helpers (reuses sibling repo .venv)
```
